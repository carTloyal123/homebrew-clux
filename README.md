# homebrew-clux

Homebrew tap for [clux](https://github.com/carTloyal123/clux), a terminal
multiplexer focused on UX.

```sh
brew install carTloyal123/clux/clux
```

or

```sh
brew tap carTloyal123/clux
brew install clux
```

macOS only (Apple Silicon and Intel). The formula installs prebuilt binaries
from the clux GitHub releases — no compiler required. `clux` spawns `clux-server`
on first use; both are installed together.
